# TradingView Drawing Tool Icons & Visual Reference Catalog

A comprehensive visual catalog, SVG icon specification, and reference guide for TradingView drawing tools, covering vector representations, engine identifiers, default hotkeys, geometry definitions, and official TradingView Help Center documentation.

---

## 1. Overview & Architecture

TradingView's left-hand drawing toolbar organizes over 50 analytical, geometric, forecasting, and measurement instruments into modular, expandable categories. Each tool is represented by a crisp, minimalist vector icon designed for high clarity at sizes ranging from 16×16 to 28×28 pixels.

In this project, the drawing tool visual system is unified across:
- **Icon Assets**: `frontend/src/ui/icons.ts` (lightweight, zero-dependency SVG paths utilizing `currentColor`).
- **Engine Typing & Registry**: `frontend/src/drawings/drawing-types.ts` (`DrawingType`, `TOOL_CATEGORIES`, handle definitions).
- **Shortcut Dispatcher**: `frontend/src/drawings/drawing-shortcuts.ts` and `docs/tradingview-drawing-shortcuts.md`.
- **Architectural Model**: `docs/adr/0003-drawing-tools-architecture-and-interaction-model.md`.

## 4. Vector Specifications & Rendering Rules

### SVG Standards
1. **ViewBox**: Standardized to `viewBox="0 0 28 28"` (native TradingView Supercharts coordinate space) and `viewBox="0 0 24 24"`.
2. **Stroke & Geometry**:
   - Primary line strokes: `stroke="currentColor" stroke-width="2"` (or `fill="currentColor"` for solid contour paths).
   - Line cap & joins: `stroke-linecap="round" stroke-linejoin="round"`.
   - Control handles: Concentric double-ring circular handles (`1.5px` inner radius with `2.5px` outer boundary).
3. **Theming**:
   - In light mode: strokes adapt dynamically to `#131722` (neutral dark) or `#2962ff` (TradingView active blue).
   - In dark mode: strokes adapt dynamically to `#d1d4dc` (light slate) or `#2962ff` (accent).
   - Position & Risk/Reward fills utilize standard opacity `0.30`–`0.35` (`#089981` bull emerald green, `#f23645` bear crimson red).
